Pill-shaped call-to-action button, used for primary actions like "Book a Consultation" or "Explore Our Work".

```jsx
<Button variant="primary" size="md" onClick={() => {}}>Book a Consultation</Button>
```

Variants: `primary` (olive fill), `secondary` (terracotta fill, sparing use), `outline` (hairline border), `ghost` (text-only, for tertiary actions). Sizes: `sm`, `md`, `lg`. Hover darkens the fill; no scale/bounce on press, consistent with the brand's calm motion language.
