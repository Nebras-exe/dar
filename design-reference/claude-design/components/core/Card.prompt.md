Two variants sharing one component: `service` (icon-badge + title + description, used in "What We Do") and `project` (photo + title + location, used in the project grid).

```jsx
<Card variant="service" icon="🪑" title="Full-Service Interior Design" description="From concept to completion, we handle every detail with care." />
<Card variant="project" image="/room.jpg" title="Sagewood Residence" meta="Austin, Texas" />
```
