# Imported Furniture Catalog — Source Report

Generated by `scripts/import-local-furniture.mjs` from a locally-saved furniture
gallery. Prices are **estimated** (demo), and every product records its
provenance. No paid APIs, no credits, no live Claude API calls were used. Images
were fetched with plain HTTP GETs and stored locally.

Classification is driven by the **product-page href** (which carries the real
English product type), so sofa-beds that lived in the gallery's "beds" bucket
(VIMLE, SÖDERHAMN, KIVIK, FRIHETEN …) correctly land in **sofas**, chair pads land
in **decor**, bar stools / armchairs / rocking chairs stay in **chairs**, and
coffee vs. side vs. dining tables are separated.

## How the data is wired

```
scripts/import-local-furniture.mjs   (deterministic parser/classifier/pricer)
        │  reads  D:\downlading\ikea_furniture_gallery (1).html   (read-only)
        ▼
src/lib/catalog/ikea-catalog.data.ts   (GENERATED — RawProduct[] + RawVariant[])
        ├──▶ src/lib/catalog/products.ts        → Product[]  (base catalog)
        └──▶ src/lib/catalog-preview/variants.ts → PRODUCT_VARIANTS (per-colour photos)
        ▼
public/images/catalog/<slug>/<colour>.jpg   (local real photos, 788 files)
```

Everything downstream is unchanged and now grounded on this data:

- **Shop / categories** — populated; category counts reflect the import.
- **Product pages** — gallery, estimated-price badge, variant switching, dimensions
  (with an "approximate" note when unknown), source label.
- **Variant switching** — selecting a swatch shows that colour's own real photo
  (unique colour id per product; extra same-colour photos fold into the gallery).
- **Catalog Agent / Interior Engine / chatbot** — already read the pure catalog
  (`filterProducts` / `getProductBySlug`) and the variant layer (`variantsFor`),
  so recommendations are **catalog-only**; unknown ids are rejected, never invented.
- **Budget** — computed deterministically from catalog (estimated) OMR prices.

## Pricing

Prices are deterministic **estimates** in OMR, assigned by category/subcategory
price bands with a slug-seeded offset (and a mild size factor for tables / beds /
sofas when real dimensions were available). Colour-only variants share the base
price (no arbitrary deltas). Every price surface labels this as **Estimated /
تقديري**. See `BANDS` in the importer for the exact bands.

## Re-running the import (safe / resumable)

```bash
node scripts/import-local-furniture.mjs --dry      # stats only, writes nothing
node scripts/import-local-furniture.mjs            # regenerate ikea-catalog.data.ts + manifest
node scripts/download-catalog-images.mjs           # resumable; skips files already present
```

The importer is a pure function of the source HTML — re-running reproduces
identical ids, slugs, and prices. Adding more furniture later (new blocks in the
source, or hand-authored `Product` records) is picked up automatically by the
catalog, agent, and chatbot; no product ids are hardcoded into any prompt.
