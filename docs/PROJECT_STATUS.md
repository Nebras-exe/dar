## Important architectural decisions

- **`[locale]` URL routing** (`/en`, `/ar`) with `src/proxy.ts` for locale negotiation — correct server-side `dir`/`lang`, no client flash.
- **Custom design system** (no UI library) to achieve a premium, non-template look.
- **Single warm light theme** committed via CSS-variable tokens mapped into Tailwind v4 `@theme`.
- **One runtime dependency added** (`lucide-react`); fonts self-hosted via `next/font`.
- **Next 16 `proxy` convention** adopted (renamed from `middleware`).

## Known issues / limitations (through Phase 03)

- **Real interior/furniture photography still needed.** Product imagery is deterministic generated SVG art (category-differentiated, tinted by real swatches); no external assets ship. `ProductImage` renders `next/image` automatically once a product has real `images` — a data change, not a code change.
- **Mobile & browser click-through verified by code review + HTTP, not screenshots.** The Chrome extension did not connect this session, so live click-through and device emulation were unavailable (mobile emulation was already unavailable in Phase 02). Routes/RTL/filter-sort matrix were verified over HTTP against the dev server; client cart/favourites via unit-tested pure logic.
- Header Account and the Custom/Supplier CTAs remain **shell / coming-soon**; **Try in My Room** and **checkout** are intentionally disabled ("later phase"). Shop / Search / Cart route to real Phase 03 pages; **Design My Space now routes to the real Phase 04 `/[locale]/design`**.
- The AI Designer recommendation is **deterministic** (no LLM); the design result is a structured plan, not a generated room image.
- **Room analysis (Phase 05) is optional and consent-gated.** With no provider key configured (current state), the designer runs fully manually and can show a clearly-labelled **sample** analysis. When a key is set, the room photo is sent **server-side** to the chosen provider (with explicit consent) and processed transiently — never stored. Physical dimensions are never inferred from a photo.
- **The AI Agent (Phase 06) is optional.** With no key configured (current state) it runs as the deterministic **Demo Agent** (real catalog tools, no LLM), clearly labelled. When a key is set, an LLM orchestrates the same allowlisted tools server-side. The Agent never invents products/prices/dimensions/totals, and the cart is never committed without explicit user approval. All provider secrets are server-only; enable via `.env.example` (`ANTHROPIC_API_KEY` / `OPENAI_API_KEY`; optional `ATHATHI_AGENT_PROVIDER`/`ATHATHI_AGENT_MODEL`, `ATHATHI_VISION_*`, `GOOGLE_GENERATIVE_AI_API_KEY`).
- All catalog data is **sample/demo** (`isDemo`, "Sample" badge, fictional demo suppliers); **no fake ratings/reviews/discounts/stock-urgency**. No backend/AI/auth yet.
- Cart/favourites persist in `localStorage`; all money math is numeric 3-decimal OMR via `computeSubtotal`/`formatOmr` (never formatted strings).
