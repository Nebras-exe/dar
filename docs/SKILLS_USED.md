## Phase 01 — Foundation & Design System

**Actually used**

- **`frontend-design`** — aesthetic direction: commit to a bold, cohesive premium-interior identity and avoid generic AI-template aesthetics (no Inter/purple-gradients/cookie-cutter layouts); distinctive typography and intentional spacing/motion. Shaped tokens, fonts, and the showcase page.
- **`web-design-guidelines`** — fetched the live Vercel Web Interface Guidelines and used them as the build-and-review checklist (accessibility, focus, forms, i18n, RTL, motion, typography).

**Evaluated, correctly not used**

- **`design-system`** — turned out to be a game-GDD generator, not a web design-token tool. Not applicable.

**Relevant, deferred to later phases**

- `code-review` / `ui-ux-pro-max` (larger feature reviews), `vercel-react-best-practices` (data/server-component patterns), `localize` (bulk translation), `webapp-testing` (E2E once flows exist), motion skills (`css-animations`, `microinteractions`) for marketing/feature polish.
